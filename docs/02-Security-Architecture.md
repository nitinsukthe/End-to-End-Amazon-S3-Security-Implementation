# Security Architecture

## Overview

The architecture demonstrates how security controls interact to protect data stored within Amazon S3.

---

## Architecture Components

### User

Authorized administrator responsible for managing the S3 environment.

### IAM User

Provides authenticated access to AWS resources based on assigned permissions.

### Amazon S3 Bucket

Primary storage location containing protected data.

### AWS KMS

Provides encryption key management and data-at-rest protection.

### Bucket Policy

Enforces secure access controls and HTTPS-only communication.

### Block Public Access

Prevents accidental public exposure of bucket contents.

### S3 Versioning

Maintains multiple object versions to support recovery operations.

### Access Logging

Records access requests and bucket activity for auditing.

### Log Bucket

Stores access logs generated by Amazon S3.

---

## Security Benefits

- Data confidentiality through encryption
- Protection against accidental public exposure
- Auditable storage access
- Recovery from accidental deletion
- Secure transport enforcement
